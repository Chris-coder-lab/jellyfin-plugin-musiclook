# Verhaltensregeln / Code of Conduct

Dieses Projekt soll ein freundlicher Ort für alle sein, die Jellyfin und Musik mögen.

## Was wir erwarten
- Respektvoll und sachlich bleiben, auch bei Meinungsverschiedenheiten.
- Kritik an Code und Ideen ist willkommen, persönliche Angriffe nicht.
- Anderen die Zeit geben, die sie brauchen: Dieses Projekt wird in der Freizeit gepflegt, Antworten können dauern.
- Keine Beleidigungen, Diskriminierung, Belästigung oder Drohungen, weder in Issues noch in Pull Requests oder Kommentaren.
- Keine privaten Daten anderer veröffentlichen.

## Was passiert bei Verstößen
Beiträge, die gegen diese Regeln verstoßen, können bearbeitet, ausgeblendet oder gelöscht werden; wer wiederholt dagegen verstößt, kann vom Projekt ausgeschlossen werden.

## Meldungen
Verstöße bitte über die Funktion „Report“ von GitHub an die Projektbetreuer melden oder ein Issue ohne Einzelheiten eröffnen und um privaten Kontakt bitten.

Diese Regeln sind an den Grundgedanken des [Contributor Covenant](https://www.contributor-covenant.org/) angelehnt.
