# Sicherheit

Wenn du eine Sicherheitslücke findest (z. B. Zugriff auf Playlists anderer Benutzer, ungeprüfte Eingaben in den Plugin-Endpunkten), melde sie bitte **nicht** öffentlich als Issue.

Nutze stattdessen auf GitHub unter *Security → Report a vulnerability* („Private vulnerability reporting“), falls das im Repository aktiviert ist. Ist es nicht aktiviert, eröffne ein Issue ohne technische Einzelheiten („Sicherheitsproblem – bitte um privaten Kontakt“), dann wird ein privater Weg vereinbart.

Unterstützt wird jeweils die neueste veröffentlichte Version.
